# Modern Video Player

A modern and interactive video player built with **HTML, CSS, and JavaScript**.

The project provides custom video controls with a simple and clean interface.

## Features

* Play and pause the video
* Stop and restart the video
* Mute and unmute
* Enable and disable loop
* Fullscreen mode
* Change playback speed
* Adjust video volume
* Control video progress
* Forward and backward by 10 seconds
* Change video size
* Display current time and video duration

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Download or clone the project.
2. Make sure `universe.mp4` is in the project folder.
3. Open `index.html` in your browser.
4. Use the controls to interact with the video player.
